## One university, multiple routes

Paths — routes through the same faculties and principles. Not separate universities. Not folder trees.

Every path obeys: Completeness pyramid · problem-first · Interview Readiness · progressive difficulty · honesty · Levels 1–3.

## Path Alpha — Software Engineer (Student A)

**Goal:** SE breadth + Mobile depth + dual AI + Leadership judgment.  
Commercial foundation остается iOS — не потолок identity.

**Not goal:** isolated iOS API tours or “become AI Engineer” identity.

### Lesson contract

Senior+/Lead contract in [03_CURRICULUM.md](03_CURRICULUM.md) + Levels when useful.

### Spine (problem classes)

1. SE foundations (design, architecture as response to change, testing strategy)  
2. Mobile Systems depth (Swift/concurrency/UI as decision cases)  
3. Technical Ownership & Decision Making (Leadership)  
4. AI-assisted workflows (Track 1) — tools inside real work  
5. AI Technology spine (Track 2) — understanding, не hype  
6. Backend / data / networking as SE systems thinking  
7. Infrastructure / CI/CD / observability as delivery craft  
8. Leadership depth (standards, review, mentoring, product judgment)  
9. Career Story & Interview Engineering — honest only  
10. WWDC / Evolution / paper deepdives via Skills → Evidence  

Detailed stage table: [campus/paths/alpha.md](campus/paths/alpha.md).

## Path rules

1. Advance only with Evidence.  
2. Technologies = decision cases.  
3. Skills produce learning modules, not vanity summaries.  
4. Private career facts never enter path logs.  
5. Paths may revise without mass file migration.
