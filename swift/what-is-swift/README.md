## Интуиция

В главе 0 модуля Execution Spine ты увидел цепочку:

> задача → человек → алгоритм → программа → Compiler → Machine Code → CPU → действие в мире

Swift стоит на ступени **программа**: это форма записи, удобная инженеру. Процессор по-прежнему исполняет Machine Code. Swift не отменяет Execution Spine — он делает верхнюю ступень человечнее.

---

## Зачем вообще новый язык?

До Swift на Apple-платформах главным языком был **Objective-C**: мощный, но тяжёлый для чтения и безопасной эволюции больших приложений.

Боль была знакомая из истории программирования: *как сказать машине однозначно — и при этом не утонуть в шуме синтаксиса*.

Swift (2014, Apple) отвечает на эту боль:

- читать и писать проще, чем типичный Objective-C;
- типы и безопасности помогают ловить ошибки раньше;
- тот же мир Apple (Cocoa / iOS / macOS), но другой язык общения.

> Менялся язык общения с платформой. Идея не исчезла: точные инструкции для буквального исполнителя.

---

## Краткая линия

```text
C → Objective-C → Swift
         ↑
    (Apple platforms)
```

Имена — ориентиры. Вывод:

| Было больно | Что дал Swift |
|-------------|----------------|
| Много шума вокруг простой идеи | Короче выражать алгоритм |
| Легко промахнуться с памятью / типами | Жёстче контракты на этапе компиляции |
| Сложно онбордить людей | Ближе к «обычному» инженерному языку |

Глубже про Compiler и Machine Code — в модуле Execution Spine, не здесь.

---

## Где Swift на Execution Spine

```text
Реальная задача
  → Человек
  → Алгоритм
  → Программа   ← Swift (форма записи)
  → Compiler
  → Machine Code
  → CPU
  → Действие в мире
```

Когда в Engineering Builder пишут пример на Swift — это **иллюстрация формы**, а не доказательство, что программирование = Swift.

---

## Конспект

Сплошной текст, без ссылок. Указатели — в блоке ниже.

- Swift — язык записи программ для экосистемы Apple.  
- Он не исполняется «как текст»: его переводит **Compiler**.  
- Появился, чтобы упростить точное общение с машиной по сравнению с Objective-C.  
- В картине мира Engineering Builder Swift — ступень *программы*, не вся вертикаль.
