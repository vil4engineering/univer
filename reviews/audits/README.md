# Monthly audit journal

Durable log of **repo-wide Reviewer audits** (not per-chapter Accept).

Playbook: [`.ai/workflows/monthly-audit.md`](../../.ai/workflows/monthly-audit.md).

```text
reviews/audits/
  README.md
  YYYY-MM-monthly-audit.md
```

Each run records: date · Reviewer stance · counts by severity · top blockers · routing (Draft→Review vs direct fix). Full tables may live in chat; this file is the fact of the run for the knowledge base.
