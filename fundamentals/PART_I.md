> **Как задача человека превращается в действие компьютера?**

Это ядро CS здесь: не «список языков», а путь от задачи в мире до действия машины. Каждая глава — один вопрос.

---

## Модель: Execution Spine

```text
Реальная задача
  → Человек
  → Алгоритм
  → Программа
  → Compiler
  → Machine Code
  → CPU
  → Действие в мире
```

Термины spine — в [Glossary](../glossary/) (Algorithm, Compiler, Binary…).

---

## Ментальная модель: завод

Не определения — одна картина, чтобы не путать роли.

| Роль на заводе | В Computer Science |
|----------------|-------------------|
| Строитель завода | <a class="eu-term" href="../glossary/#glossary-compiler">Compiler</a> — собирает программу |
| Завод в коробке | Бинарный артефакт (например Mach-O) — «завод», который ещё не запущен |
| Государство: земля, электричество, инфраструктура | Operating System — Process, память, файлы |
| Управляющий уже работающим заводом | Runtime — обслуживает запущенную программу |
| Станки | <a class="eu-term" href="../glossary/#glossary-cpu">CPU</a> — исполняет machine code |
| Участок / смена | <a class="eu-term" href="../glossary/#glossary-process">Process</a> / <a class="eu-term" href="../glossary/#glossary-thread">Thread</a> |

После этой модели Compiler и Runtime не смешиваются: один **строит**, другой **ведёт уже работающее**.
