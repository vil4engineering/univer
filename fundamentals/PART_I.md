# Computer Science

Вход в Computer Science — первый модуль траектории [Foundations](../campus/paths/beta.md).

Главный вопрос модуля:

> **Как задача человека превращается в действие компьютера?**

Это и есть ядро CS здесь: не «список языков», а путь от задачи в мире до действия машины.

Каждая глава отвечает на **один вопрос**, а не определяет термин.

---

## Модель: Execution Spine

Так мы называем вертикаль этого модуля. Дальше главы говорят: «мы на уровне *Compiler* Execution Spine».

```text
Реальная задача
  → Человек
  → Алгоритм
  → Программа
  → Compiler
  → Machine Code
  → CPU
  → Действие в мире
```
