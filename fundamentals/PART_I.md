> **Как задача человека превращается в действие компьютера?**

Это ядро CS здесь: не «список языков», а путь от задачи в мире до действия машины. Каждая глава — один вопрос.

---

## Модель: Execution Spine

```text
Реальная задача
  → Человек
  → Алгоритм
  → Программа
  → Compiler
  → Machine Code
  → CPU
  → Действие в мире
```

Термины spine — в [Glossary](../glossary/) (Algorithm, Compiler, Binary…).
