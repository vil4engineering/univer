# Neural Network

Russian: нейронная сеть

Category: Fundamentals

Importance: Essential

Status: full

## Definition

Neural Network — вычислительный граф из слоёв с **параметрами (весами)**. Вход преобразуется слоями в выход (класс, вектор, распределение токенов).

## Why it matters

Даёт язык для «что внутри модели»: параметры, слои, forward pass = inference. Нужен для разговоров про fine-tuning, размер модели и latency.

## Example

Маленькая сеть классифицирует intent «создать задачу» / «удалить»; большая Transformer-сеть — LLM для чата.
