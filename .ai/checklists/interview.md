# Checklist: Interview

- [ ] Expected time band present (30s / 2–3m / whiteboard)
- [ ] Each item references a canonical topic
- [ ] No second full explanation of the concept
- [ ] Short answer is pointer-level, not a lecture
- [ ] Senior sketch is bullets + links, not a second essay
- [ ] Follow-ups go deeper (why / trade-offs / failures / “why not X?”)
- [ ] Common mistakes listed
- [ ] Production example present or honest TODO
- [ ] Level/Heat appropriate; not trivia-only
- [ ] No invented private experience
- [ ] Live Interviewer mode: no explanations unless debrief requested
