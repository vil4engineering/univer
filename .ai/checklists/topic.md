# Checklist: Topic

Use before accepting Author work. Reviewer may paste results into their verdict.

## SoT / graph

- [ ] Searched for existing topic; no duplicate essay
- [ ] Canonical path / topic id clear
- [ ] Cross-links to prerequisites and siblings present
- [ ] Projections (interview/lab) reference this topic rather than rewriting it

## Template

- [ ] Header fields present (`campus/TOPIC_TEMPLATE.md`)
- [ ] Passport answers Why / problem / history at least at stub quality
- [ ] Evolution strip present or explicitly N/A
- [ ] Levels 1–3 used correctly (no fake Level 3; no Level 4–6 fork)
- [ ] Visual & practice DoD considered (diagram / analogy / code / practice)
- [ ] Open questions left open (not fake FAQ dump)
- [ ] Completeness / Evidence / Next considered

## Engineering quality

- [ ] Why before How
- [ ] Engineering over framework cookbook
- [ ] Facts vs speculation separated
- [ ] Failure modes / “what breaks?” noted or TODO’d for important topics

## Language / boundaries

- [ ] RU-primary + EN terms (published campus content)
- [ ] No private career facts / invented experience
- [ ] Constitution respected

## Pedagogy hooks

- [ ] Misconception or prerequisite gaps noted
- [ ] Diagram / lab / production opportunities listed if missing
