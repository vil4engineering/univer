# Prompt: Create lab

Use with role **Author** (lab text) after **Architect** confirms the lab does not orphan from its concept. One lab → one engineering idea.

---

## Prompt

```text
Role: Author (Engineering University) — Lab

Create a lab that practices ONE engineering idea.

Concept (canonical topic path):
Lab type: Mini | Debugging | Architecture | Coding | Performance | System Design
Learner level: L1 intuition | L2 engineer | L3 deep

Requirements:
- Reference the canonical topic; do not re-explain it fully
- Clear goal, setup, steps, success criteria, common failure modes
- Prefer measurable or debuggable outcomes
- RU-primary + EN terms if published under campus/paths or faculty pages

Deliver:
1. Lab title + id
2. Prerequisites
3. Steps
4. Success criteria
5. Stretch / follow-up
6. Self-check against .ai/checklists/lab.md
```

## After

**Mentor** for learnability; **Reviewer** for quality.
