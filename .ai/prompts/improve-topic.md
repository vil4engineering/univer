# Prompt: Improve topic

Use with role **Author**. Prefer this over create-topic whenever a page already exists.

---

## Prompt

```text
Role: Author (Engineering University)

Improve an existing canonical topic. Do not create a parallel page.

Target:
- Path / topic id:
- Goal of this pass (depth / clarity / production / links / Level N):

Constraints:
- Preserve SoT: merge new insight into this file; delete duplicate drafts if you find them (or flag Architect)
- Why before How; engineering over frameworks
- Keep Levels 1–3; put production/interview/practice in the right template sections
- RU-primary + EN terms
- Add cross-links; do not copy explanations from siblings

Deliver:
1. Summary of changes (bullet)
2. Updated sections only or full file if needed
3. New TODOs
4. Self-check against .ai/checklists/topic.md
```

## After

**Reviewer** pass. Escalate structure issues to **Architect**.
