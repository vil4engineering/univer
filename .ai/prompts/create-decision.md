# Prompt: Create decision

Use with role **Author**. Default landing place: a **Decision** section on the related canonical topic (or Path note). Escalate to Architect if someone proposes a new Decision Book / `handbook/` tree.

Must reference canonical concept topics; do not re-teach them.

---

## Prompt

```text
Role: Author (Engineering University) — Engineering Decision

Default target: section on canonical topic path (not a new warehouse root).
Escalate Architect if a new Decision Book tree is requested.

Title:
Canonical topic path:
Context / system:

Fill:
- Problem
- Context / constraints
- Alternatives
- Trade-offs
- Chosen solution
- Consequences
- Would you make the same decision today?
- Real production example OR explicit TODO (do not invent)

Rules:
- Facts vs opinions labeled
- Link SoT topics instead of duplicating explanations
- Engineering over fashion
- No top-level Decision Book until Design revision

Deliver decision section + links + open questions.
```
