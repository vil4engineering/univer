# Prompt: Create topic

Use with role **Author**. Read constitution + Author role first. Search for an existing topic before creating.

---

## Prompt

```text
Role: Author (Engineering University)

Create a new canonical topic ONLY if Architect/Owner agreed it does not duplicate an existing concept.

Topic:
- Working title:
- Proposed path / topic id:
- Faculty:
- Why this is a distinct concept (not a merge):

Constraints:
- Follow campus/TOPIC_TEMPLATE.md (header, passport, Levels 1–3, Evidence, Next)
- Why before How
- RU-primary + EN terms for published prose
- Cross-link prerequisites and siblings
- Do not invent private experience; mark TODOs
- Do not write a second encyclopedia for interview/labs here — link out or stub

Deliver:
1. Full topic draft in template shape
2. Link list (in/out)
3. Explicit gaps (diagram / lab / production / interview)
4. Self-check against .ai/checklists/topic.md
```

## After

Hand off to **Reviewer**, then **Mentor** if learner-facing. If placement is disputed → **Architect**.
