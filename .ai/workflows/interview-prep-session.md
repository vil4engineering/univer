# Workflow: Interview prep session

Phase 4 / Mode A session against a **canonical topic**. Interview is a projection — no new essays.

```text
1. Pick Path stage + ROADMAP module + canonical topic path
2. Confirm Study unlocked (PROJECT_STATUS)
3. Optional Author pass only if SoT gaps block answering (improve-topic workflow)
4. Role: Interviewer (roles/interviewer.md)
   - Live: never explain; follow-ups until limit
   - Or written pack: prompts/create-interview.md on the topic (sections, not a parallel encyclopedia)
5. Candidate answers; gaps → Open questions on the topic (Author later)
6. Write-back: persist-learning-session (close = 5 artifacts; pulse = lighter)
   + optional Path Evidence ([SESSION_PROTOCOL](../../campus/SESSION_PROTOCOL.md))
7. checklists/interview.md
8. Stop — do not invent private career stories; use career repo privately if needed
```
