## In 30 seconds

On-demand resources (ODR) and `NSBundleResourceRequest` are deprecated toward **iOS 27**. Apple points new work at **Background Assets** for hosted content separate from the main bundle (size, install speed, optional features).

## Action

- New downloads / hosted packs → Background Assets APIs.
- Existing ODR → plan migration; do not start new ODR tags.
- Interview: know *why* ODR existed (thin install) and what replaces the request API.
