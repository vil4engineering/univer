# Engineering University

Научись понимать, как устроены компьютеры, программирование и современные инженерные системы — от первых принципов до уровня, нужного современному Software Engineer.

Это не справочник API и не каталог технологий. Каждая глава отвечает на фундаментальный вопрос и постепенно строит твою инженерную картину мира.

> Главы отвечают на *почему*, а не на «что такое термин».
