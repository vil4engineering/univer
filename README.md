# Engineering Builder

Тимур, это **Engineering Builder** для тебя — витрина мира IT в одном месте.

IT как конструктор: кубики продуктов (Mobile, Backend, Frontend, AI, Leadership…) стоят на **фундаменте** Computer Science + Mathematics. Без фундамента этажи не держатся.

Главы отвечают на *почему*. Термин с оттенком ведёт сразу в [Glossary](glossary/) (тот же, что в сайдбаре).  
**Mobile / iOS** будет глубже; остальные этажи наполняем базой. Новое всегда ссылается на фундамент.
