## Чем это отличается

- Главы отвечают на **почему**, а не на «что такое термин»  
- Идеи важнее каталогов фреймворков  
- Практика и Evidence важнее «прочитал и забыл»  
- Swift / iOS — сильная специализация, не старт всей картины
