# Operating modes

## Mode A — Full-time Interview Bootcamp (now)

While job-seeking: the day *is* the job.

Example skeleton (adjust, keep the shapes):

| Block | Duration | Focus |
|-------|----------|--------|
| Morning pulse | 20–30 min | Swift/iOS news, WWDC, Evolution — update related topics if needed |
| Deep study | 2–3 h | One competency · onion · whole picture · until closed or parked with gaps listed |
| Practice | 1–2 h | Lab / Core World / Sandbox code |
| Spaced review | 45–60 min | Old high-heat topics |
| Mock interview | 1–2 h | Interviewer mode · challenge answers · write Evidence |

Do not start the next competency until Evidence/`interview_ready` rules say so ([PROGRESS.md](PROGRESS.md)).

Open questions stay on the topic page; answers get forged in chat/mocks, then written back.

## Mode B — Employed maintenance (later)

No 8-hour days.

| Block | Duration | Focus |
|-------|----------|--------|
| Morning | 15–20 min | News / Evolution / light review |
| Evening | 40–60 min | One topic slice — **no heavy overload late** |

Weekly: short mock on studied set.  
Monthly: WWDC/ecosystem delta pass.

## Source order (every topic)

1. Apple Documentation  
2. WWDC  
3. Swift Evolution / proposals  
4. Relevant sources / runtime when needed  
5. Strong external explanations (including paid Boosty-style materials) as **ideas**, never copy-paste
