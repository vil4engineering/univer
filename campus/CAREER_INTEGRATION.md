# Career integration (hybrid)

**Private Career OS** живёт вне этого репо. University — learning system, который адаптируется к market через pipeline.

## Pipeline

```text
Market
  → Career OS (private: CRM, salary, personal strategy)
  → Skill Gap
  → Learning Plan
  → Engineering University
  → Practice / Labs / Skills
  → Portfolio Evidence
  → Career OS
```

## What lives where

| Concern | Where |
|---------|--------|
| Salary, recruiter strategy, private weaknesses, CRM | `career` repo only |
| Competency / Skill gaps (teachable) | Bridged via Learning Plan → Path stages |
| Interview craft (answer depth, narration structure) | Faculty Career Development + Leadership 09–10 |
| Deepdive / audit Skills | `campus/skills/` |
| Employer names, local paths, secrets | Never in public university content |

## Skills that touch career

- `career-gap-analysis` / `career-review` — **themes only**, no private facts pasted into public pages.  
- Output: which Path stages / faculties to prioritize — not CRM updates.

## Assistant rule

Repo learning assistant must refuse to publish private career material into `ios-university`. Manual: [ASSISTANT_MANUAL.md](ASSISTANT_MANUAL.md).
