# Faculties

Факультеты — **карта узлов** графа знаний: *где в системе живёт эта тема?*

Это не маршрут обучения. Маршрут (порядок обхода) — в [Траекториях](../paths/).  
Faculties и Paths не конкурируют: одно — карта, другое — рекомендованный путь по карте.

Пока идёшь по Foundations / Part I, сюда можно заглядывать из любопытства. Глубоко — когда траектория сама подведёт.
