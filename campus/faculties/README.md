# Faculties

Факультеты — карта узлов графа: *где в системе живёт эта тема?*

Они стоят **сбоку** от учёбы: не вместо Foundations и не вместо [траекторий](../paths/).  
Траектория говорит, *в каком порядке идти*. Факультет — *в каком крыле университета лежит тема*.

Пока идёшь по Foundations / Execution Spine, сюда можно заглядывать из любопытства. Глубоко — когда глава или траектория сама даст ссылку.
