# Progress & Knowledge Registry

Interview OS tracking lives **in this repository** (not a second SOT).

## Topic status

| Status | Meaning |
|--------|---------|
| `not_started` | Not opened |
| `learning` | Layers 0–2 in progress; reading alone stays here |
| `practicing` | Code / lab / exercises underway |
| `interview_ready` | Can answer Senior questions with Evidence |
| `mastered` | Evidence complete + can teach; revisit later |

“I think I get it” is never `mastered`.

## Confidence

1–5 self rating. Be harsh. “Seems clear” → 2 or 3 max.

## Evidence checklist (default)

- [ ] Explained in own words (RU)  
- [ ] English for Interview line  
- [ ] Answered mock questions  
- [ ] Wrote / ran code  
- [ ] Under-the-hood at agreed layer  
- [ ] Solved at least one exercise  

Topic reaches `mastered` only with Evidence, not vibes.

## Interview Heat

| Heat | Examples |

| ★★★☆☆ | Performance deep, Security deep |
| ★★☆☆☆ | Macros, Regex DSL, niche APIs |

Close high-heat gaps first during full-time mode.
