# Для Тимура — как пользоваться библиотекой (с агентом)

**Кто ты:** ученик + можешь добавлять материалы на **существующих** полках.  
**Кто не ты в этом репо:** владелец архитектуры (сайдбар, IA, `.ai/`) — это Максим.

Голос глав — **ты** (к тебе). Это **библиотека**, не домашний журнал и не план «обязательно пройди Evidence». Учись когда можешь: открыл ссылку → разобрался.

---

## Первый раз открыл репо / чат с агентом

1. Скажи агенту: **«Я Тимур»** (он обязан спросить, если не знает — см. [`AGENTS.md`](../AGENTS.md)).  
2. Попроси прочитать **этот файл**, потом задачу.  
3. Не проси «продолжай следующую главу concurrency / заполни полку» без явной темы от Максима — агент в режиме Тимура **не** строит библиотеку как Owner.

Максим может просто скинуть ссылку на главу (браузер или Cursor). Как устроены ссылки: [LINKING.md](LINKING.md).

**Примеры ссылок (Pages):**

| Куда | URL |
|------|-----|
| Home | `https://vil4labs.github.io/univer/` |
| Computer Science | `https://vil4labs.github.io/univer/#/fundamentals/PART_I.md` |
| Гл.0 — зачем программы | `https://vil4labs.github.io/univer/#/fundamentals/what-is-programming/` |
| Гл.1 — исполнитель | `https://vil4labs.github.io/univer/#/fundamentals/literal-executor/` |
| Concurrency hub | `https://vil4labs.github.io/univer/#/swift/concurrency/` |

В Cursor: открой ту же папку `README.md` или скажи путь темы агенту.

## Как учить (три нормальных способа)

### A. Ссылка от Максима

Открой в браузере → читай сверху вниз → по «Дальше» или вернись в hub.  
Непонятный термин → клик `eu-term` / [Glossary](../glossary/).

### B. Агент как репетитор (рекомендуемый старт в Cursor)

```text
Я: Тимур

Прочитай campus/FOR_TIMUR.md.
Тема: [путь или ссылка, например swift/concurrency/actors-and-isolation/]
Нужно: Level 1 объяснение своими словами + 3 вопроса на проверку (сначала я отвечу).
Не: менять сайдбар / IA / .ai; не коммитить; не выдумывать «что я уже прошёл».
```

Потом можно: «разбери Пример», «проведи мини-мок», «свяжи с Glossary Sendable».

### C. Идёшь сам по полке

1. Фундамент: [PART_I](../fundamentals/PART_I.md) → гл.0 → гл.1.  
2. Mobile / concurrency: hub [Reading route 0→12](../swift/concurrency/) — с любой главы, если Максим дал ссылку.  
3. Один why за раз. Не десять тем за вечер.

Playground рядом с главой — практика **по желанию**, не гейт «страница ненастоящая».

## Как спрашивать агента

| Хочешь | Скажи примерно так |
|--------|---------------------|
| Понять главу | «Объясни эту README на Level 1, потом Level 2» |
| Проверить себя | «Задай 5 вопросов; ответы покажи после моей попытки» |
| Термин | «Добавь / найди в Glossary: … Domain: …» (см. [HOW_TO_ADD](HOW_TO_ADD_WITH_AI.md)) |
| Связь тем | «Зачем эта глава после предыдущей? Одна картинка» |
| Мок | «Сыграй интервьюера по Interview-Pack этой полки» |

**Не проси (агент должен отказать или отправить к Максиму):**

- поменять `_sidebar`, IA, `.ai/`, constitution  
- «заполни всю concurrency / следующую полку» без темы от Максима  
- commit / push без явной просьбы (и обычно это делает Максим)  
- придумать, что ты «уже закрыл Path / Evidence»  
- private career / чужие работодатели в public repo  

Добавлять Glossary / текст в **существующий** слот — можно: [HOW_TO_ADD_WITH_AI.md](HOW_TO_ADD_WITH_AI.md).

## Как работать с агентом (короткий контракт)

```text
1. «Я Тимур»
2. Одна тема / один why за сообщение (или явная ссылка)
3. Режим: объяснить | проверить | Glossary | черновик в существующий слот
4. Агент не ломает архитектуру; сомнение → к Максиму
5. Урок без «обязательного» write-back в Path — библиотека уже на месте
```

Роли агента (если полезно): coach / librarian — см. [ASSISTANT_MANUAL.md](ASSISTANT_MANUAL.md).  
Там много про Path Alpha и Mode A (интенсив Максима) — **тебе это не обязательный ритуал**. Бери оттуда: Levels 1–3, «не handbook», RU + EN terms. Игнорируй как гейт: «без Evidence урок не засчитан».
