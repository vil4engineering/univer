# AI Engineering

<small>Learning Path Gamma</small>

**Слой:** специализация поверх того же графа — не отдельный университет «про AI».

**Идея:** LLM, Transformer, GPU опираются на Memory, Compiler, Binary, исполнение.  
AI не отменяет Foundations — он *использует* их.

```text
LLM → Transformer → GPU → Memory → Compiler → Binary
```

**Сейчас:** траектория ещё не открыта для спокойного самостоятельного старта.  
Сначала [Foundations](beta.md); при необходимости слой [Software Engineering](alpha.md).

Когда Gamma откроется, здесь будут два направления: AI как инструмент инженера и AI как система — оба со ссылками вниз по графу.

Карта: [Траектории](./).
